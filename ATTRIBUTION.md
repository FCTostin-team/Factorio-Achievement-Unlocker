# Attribution and licenses

This repository contains a new implementation with its own structure, command-line interface, binary validation, edit planning, and guarded file operations. Its byte-signature profiles draw on research published in two independent projects:

- `FAE_Linux` for Linux, licensed under Apache-2.0. Its license text is retained in `third_party/FAE_Linux-LICENSE`.
- `FactorioAchievementEnabler` for Windows, with copyright notices for JixunMoe (2015) and oorzkws (2022), licensed under MIT. Its license text is retained in `third_party/FactorioAchievementEnabler-LICENSE`.

Their source files and launch scripts are not included in this repository. Future changes to the signatures based on third-party research should retain appropriate provenance.
