# Factorio-Achievement-Unlocker

[English version](README.md)

Инструмент для Windows и Linux, который готовит **отдельную копию** исполняемого файла Factorio с изменёнными проверками достижений при активных модах. Оригинальный `factorio` / `factorio.exe` не меняется. Программа работает локально и ничего не скачивает. Для создания копии нужны права записи в папку назначения.

> Поддержка зависит от конкретной сборки Factorio. Если хотя бы одна сигнатура не найдена в ожидаемом количестве, программа завершится с ошибкой и не запишет файл. Включённые профили перенесены из исследований двух прежних проектов; на текущей версии Factorio они пока не подтверждены реальным игровым бинарником.

## Быстрый старт

Нужен Python 3.10 или новее. Из папки проекта:

```sh
python -m pip install -e .
factorio-achievement-unlocker inspect "/path/to/Factorio/bin/x64/factorio"
factorio-achievement-unlocker prepare "/path/to/Factorio/bin/x64/factorio"
factorio-achievement-unlocker launch "/path/to/Factorio/bin/x64/factorio"
```

В Windows укажите полный путь к `factorio.exe`, например:

```powershell
factorio-achievement-unlocker prepare "C:\Program Files (x86)\Steam\steamapps\common\Factorio\bin\x64\factorio.exe"
```

Результат по умолчанию появится рядом с оригиналом: `factorio-unlocked` или `factorio-unlocked.exe`. Для другого расположения используйте `--output PATH`. Команда `launch` пересоздаст копию после обновления игры и затем запустит её. Параметры игры передаются повторяющимися опциями `--game-arg=VALUE`.

По умолчанию используется **отдельный файл достижений для игры с модами**. Если вы осознанно хотите использовать обычный файл достижений, добавьте `--data vanilla` к `inspect`, `prepare` или `launch`. Команды с разными режимами пересоздают управляемую копию.

Удаление подготовленной копии:

```sh
factorio-achievement-unlocker restore "/path/to/Factorio/bin/x64/factorio-unlocked"
```

Для Windows путь оканчивается на `.exe`. `restore` сверяет SHA-256 с записью рядом с копией и откажется удалять файл, если он изменён извне. Оригинал игры эта команда не трогает.

## Как устроена проверка

1. Определяется формат PE/ELF и архитектура x86-64. Поиск ведётся только в исполняемых секциях/сегментах.
2. Все сигнатуры выбранного профиля должны дать ожидаемое число совпадений. Каждое заменяемое значение проверяется отдельно; пересекающиеся изменения запрещены.
3. Изменения вносятся в память, проверяются и записываются во временный файл. Готовая копия ставится на место атомарной заменой.
4. Рядом создаётся JSON-запись с хешами оригинала и копии. Она позволяет безопасно повторить `prepare` после обновления игры и удалить созданную копию через `restore`.

Это не меняет игровые сохранения и не снимает ограничения достижений, связанные с читами или консольными командами. Перед отправкой отчёта о сбое разработчикам игры проверьте его на обычном исполняемом файле.

## Ограничения

- Сигнатуры могут измениться при обновлении Factorio. Ошибка «unsupported» означает, что нужен новый проверенный профиль; принудительного режима нет.
- Поведение запуска под Steam, включая выдачу Steam достижений, не проверено на этом компьютере. Для Steam запускайте подготовленную копию в окружении Steam и сначала проверьте результат на тестовом сохранении.
- Для параметров запуска Steam может понадобиться отдельный скрипт. CLI принимает аргументы игры, но не преобразует подстановку `%command%` от Steam.
- Windows версия использует отдельный `.exe`, а не загрузку DLL. Если конкретная сборка Factorio требует исходное имя файла, подготовленную копию придётся запускать другим способом; инструмент не меняет оригинал автоматически.
